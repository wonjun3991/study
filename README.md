# Study Vault

개인 학습 노트 + 발표 자료 Obsidian Vault.

## Structure

```
.
├── AGENTS.md              # 작업 라우팅 가이드 (먼저 읽기)
├── study/                 # 학습 노트
│   └── kubernetes-in-action/
├── presentation/          # 발표 자료
│   └── harness-engineering/
├── inbox/                 # 새 노트 기본 저장 위치
├── daily/                 # Daily notes
├── templates/             # 노트 템플릿
├── attachments/           # 이미지, 파일 첨부
└── .obsidian/             # Obsidian 설정
```

상세 라우팅 규칙은 [AGENTS.md](./AGENTS.md) 참고.

## Usage

1. Obsidian에서 이 디렉토리를 vault로 열기.
2. 새 학습 주제는 `study/<topic>/` 아래에 챕터/섹션별로 정리.
3. 발표 자료는 `presentation/<topic>/`에 분리해 보관.
4. 임시 메모는 `inbox/`에 넣고, 정리되면 `study/` 또는 `presentation/`로 이동.
